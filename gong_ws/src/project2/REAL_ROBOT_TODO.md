# Pick & Place 실물 로봇 남은 작업

## 현재 완료된 범위

- [x] Gazebo 말 10개 배치 및 물리 속성 설정
- [x] `PlacePiece(cell_id)` ROS 2 Action 정의
- [x] MoveItPy 기반 Pick & Place 단계 구현
- [x] 0~8 칸 번호를 시뮬레이션 좌표로 변환
- [x] Gazebo에서 중앙 칸 배치 검증
- [x] 시뮬레이션용 말 attach/detach 보정

## 1. 말판 없이 지금 가능한 작업

### 실물/시뮬레이션 모드 분리

- [ ] launch에 `use_sim` 옵션 추가
- [ ] `use_sim:=true`일 때만 Gazebo를 실행
- [ ] `use_sim:=true`일 때만 detachable joint와 `SetEntityPose` 사용
- [ ] `use_sim:=false`일 때 OpenManipulator-X 하드웨어 컨트롤러 사용
- [ ] Pick & Place 노드 내부의 `use_sim=true` 강제 설정 제거
- [ ] 시뮬레이션과 실물이 동일한 `/place_piece` Action을 사용하도록 정리

### OpenManipulator-X 기본 하드웨어 검증

- [ ] U2D2/OpenCR, 12V 전원, USB 연결 확인
- [ ] USB 포트 권한 및 udev 규칙 적용
- [ ] 토크 활성화 전 모든 관절이 안전 범위에 있는지 확인
- [ ] `open_manipulator_bringup` 하드웨어 launch 실행
- [ ] `/joint_states` 수신 확인
- [ ] `arm_controller`, `gripper_controller` 활성 상태 확인
- [ ] 관절별 저속 조작 테스트
- [ ] `home` 자세 이동 테스트
- [ ] 그리퍼 열기/닫기 테스트

### 카메라 장착 및 보정

- [ ] 그리퍼 카메라 장착 위치와 브래킷 크기 확정
- [ ] URDF에 `camera_link`, `camera_optical_frame`, 고정 조인트 반영
- [ ] 카메라 브래킷의 실제 크기를 collision geometry로 반영
- [ ] 카메라 케이블이 관절과 그리퍼에 걸리지 않는지 확인
- [ ] 실물 카메라가 `/gripper_camera/image_raw` 발행
- [ ] 실물 카메라가 `/gripper_camera/camera_info` 발행
- [ ] 카메라 내부 파라미터 보정
- [ ] Eye-in-hand 보정으로 `end_effector_link -> camera_optical_frame` 변환 측정
- [ ] 보정 결과를 TF/URDF에 반영

### 로봇 안전성과 오류 처리

- [ ] 실물 초기 속도를 10~20% 범위로 제한
- [ ] 최대 속도/가속도 파라미터를 실물용 YAML로 분리
- [ ] Action 시작 전 컨트롤러와 `/joint_states` 준비 상태 확인
- [ ] 경로 계획 실패와 실행 실패를 구분해 반환
- [ ] 그리퍼 동작 실패 코드 추가
- [ ] Action 취소 시 말을 잡고 있는지에 따른 안전 정지 처리
- [ ] 통신 두절 또는 비상 정지 시 그리퍼 상태 방침 정의
- [ ] 실물 모드에서 카메라 충돌 형상을 임의로 제거하지 않도록 수정

### Pick & Place Action 상태 관리

- [ ] 노드를 재시작해도 다시 0번 말을 집지 않도록 공급 말 상태 관리
- [ ] `piece_slot`을 Action Goal에 추가할지 팀원과 협의
- [ ] 또는 `reset_piece_inventory` 서비스 추가
- [ ] 동작 성공과 말판 배치 확인 성공을 구분
- [ ] 같은 칸에 중복 배치 요청이 들어왔을 때의 정책 협의

## 2. 임시 말판으로 할 수 있는 검증

- [ ] 종이/골판에 3x3 칸 중심을 표시
- [ ] 로봇 베이스와 임시 말판을 움직이지 않게 고정
- [ ] 말 없이 9개 칸 상공 5~10 cm까지 접근 테스트
- [ ] 중앙 칸과 모서리 4칸의 역기구학/경로 계획 확인
- [ ] 가벼운 스펀지 물체로 집기 테스트
- [ ] 임시 안전 지점에 놓기 테스트
- [ ] 5개 공급 위치에서 연속 집기 테스트
- [ ] `OBSERVE_BOARD` 임시 관찰 자세 정의

## 3. 실제 말판이 준비된 후 할 작업

### 실물 좌표 보정

- [ ] 말판을 로봇 베이스 기준으로 고정
- [ ] 로봇 말 공급 위치 5개의 X/Y/Z 측정
- [ ] 말판 9칸의 X/Y/Z를 각각 측정
- [ ] `pre_grasp_z`, `grasp_z`, `lift_z` 보정
- [ ] `pre_place_z`, `place_z`, `retreat_z` 보정
- [ ] 계산된 등간격 좌표 대신 실측 9칸 좌표 사용
- [ ] 중앙 칸 10회 반복 배치로 정밀도 측정
- [ ] 모서리 4칸 배치 확인
- [ ] 전체 9칸 접근 가능성 확인

### 말판 인식 담당자와 연동

- [ ] 9칸의 논리 번호를 `0~8` 행 우선 방식으로 통일
- [ ] 마커 검출 결과를 `EMPTY/OCCUPIED/UNKNOWN`으로 받는 인터페이스 협의
- [ ] 로봇 이동 중에는 말판 상태 판정을 잠시 멈추도록 협의
- [ ] 배치 후 `OBSERVE_BOARD` 자세로 복귀
- [ ] 팔이 영상에서 빠진 후 마커 가림 상태 확인
- [ ] 배치 확인 성공/실패 결과를 게임 조정 노드에 전달

### Minimax 담당자와 연동

- [ ] Minimax가 `cell_id` 하나만 전달하는지 확인
- [ ] `/place_piece` Action 요청/성공/실패 시나리오 협의
- [ ] Pick & Place 실패 시 게임 상태를 즉시 갱신하지 않도록 협의
- [ ] 배치 확인 후에만 로봇 말을 보드 상태에 반영

## 4. 실물 통합 테스트 순서

- [ ] 말 1개를 모서리 칸에 배치

- [ ] Minimax + 인식 + Pick & Place 전체 게임 검증

## 5. Pick & Place 담당 완료 기준

- [ ] 시뮬레이션과 실물에서 동일한 `PlacePiece` Action 사용
- [ ] 실물 로봇이 5개 말을 순서대로 집을 수 있음
- [ ] 9개 모든 칸에 충돌 없이 접근 가능
- [ ] 배치 후 로봇이 카메라 관찰 자세로 복귀
- [ ] 배치 인식 성공 후에만 게임 상태가 갱신됨
- [ ] 계획/실행/그리퍼/인식 오류가 구분되어 반환됨
- [ ] 재시작, 취소, 실패 상황에서 잘못된 말을 집지 않음
- [ ] 실행 방법, 설정값, 좌표 보정 방법이 README에 정리됨

## 담당 범위 경계

Pick & Place 담당은 다음을 보장한다.

- `cell_id`에 해당하는 실물 좌표로 안전하게 이동
- 말 집기, 이동, 놓기, 후퇴
- 하드웨어와 컨트롤러 상태 확인
- Action 성공/실패/취소 결과 제공
- 배치 후 인식이 가능한 관찰 자세로 복귀

다음은 다른 담당자의 범위로 두되 인터페이스만 협의한다.

- Minimax의 칸 선택 알고리즘
- 영상에서 말판 마커 가림을 판단하는 알고리즘
- 전체 게임 승패 판정
